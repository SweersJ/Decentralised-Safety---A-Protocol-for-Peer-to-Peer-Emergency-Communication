# Version

This version adds extended syntax highlighting based on version [0.20.0](https://marketplace.visualstudio.com/items?itemName=informal.quint-vscode) with commit [7efd616
](https://github.com/quint-co/quint/commit/7efd6167ccf3958e6028acb66bc944e4164dd83a).  

# How to use

## Windows

1. Check the version of the extension. If it is 0.20.0, the following steps can be used, otherwise the grammar needs to be compared and new additions need to be added to the `quint.tmLanguage.json` file in the folder `informal.quint-vscode-0.20.0\syntaxes`.
2. Put the content of the folder `informal.quint-vscode-0.20.0` in the folder `C:Users\<user_name>\.vscode\extensions\informal.quint-vscode-0.20.0\`. Replace <user_name> with the correct name.

## WSL

1. Check the version of the extension. If it is 0.20.0, the following steps can be used, otherwise the grammar needs to be compared and new additions need to be added to the `quint.tmLanguage.json` file in the folder `informal.quint-vscode-0.20.0\syntaxes`.
2. Put the content of the folder `informal.quint-vscode-0.20.0` in the folder `/home/<user_name>/.vscode-server/extensions/informal.quint-vscode-0.20.0/`. Replace <user_name> with the correct name.

2. Put the content of the folder `informal.quint-vscode-0.20.0` in the folder `/home/<user_name>/.vscode/extensions/informal.quint-vscode-0.20.0/`. Replace <user_name> with the correct name.
