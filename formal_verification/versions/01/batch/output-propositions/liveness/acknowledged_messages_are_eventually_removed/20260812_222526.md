## Formal verification textual message

Under acknowledgement-receive fairness, each acknowledged message identifier eventually disappears from pending and payload state.

## Explanation

This per-identifier response property requires cleanup in two locations after acknowledgement: the sender's per-receiver pending set and the payload message set. Quantification covers every peer pair and configured message identifier. A fair counterexample is an acknowledged identifier that remains in either location forever.
