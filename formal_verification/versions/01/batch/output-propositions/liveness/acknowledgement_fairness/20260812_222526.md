## Quint proposition snapshot

```quint
    temporal acknowledgement_fairness =
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies (
                        and {
                            determineAck(sender, receiver).weakFair(Set(payloadExchangeState)),
                            sendAckPayload(sender, receiver).weakFair(Set(payloadExchangeState)),
                            receiveAckPayload(sender, receiver).weakFair(Set(payloadExchangeState)),
                        }
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N:\;s\ne r\Rightarrow\bigwedge_{A\in\{\mathit{determineAck},\mathit{sendAckPayload},\mathit{receiveAckPayload}\}}\operatorname{WF}_{\{PE\}}(A(s,r))
$$

## Formal verification textual message

For every peer pair, all acknowledgement-processing actions are weakly fair.

## Explanation

This quantified conjunction covers acknowledgement determination, sending, and receipt for each peer pair. Weak fairness requires a continuously enabled stage not to be postponed forever. The assumption supports acknowledgement progress and cleanup proofs while making no claim about bounded response time.
