## Quint proposition snapshot

```quint
    temporal delivery_fairness =
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies (
                        and {
                            addMessages(sender, receiver).weakFair(Set(payloadExchangeState)),
                            sendMessagesPayload(sender, receiver).weakFair(Set(payloadExchangeState)),
                            receiveMessagesPayload(sender, receiver).weakFair(Set(payloadExchangeState)),
                            storeReceivedMessages(sender, receiver).weakFair(Set(payloadExchangeState)),
                        }
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N:\;s\ne r\Rightarrow\bigwedge_{A\in\{\mathit{addMessages},\mathit{sendMessagesPayload},\mathit{receiveMessagesPayload},\mathit{storeReceivedMessages}\}}\operatorname{WF}_{\{PE\}}(A(s,r))
$$

## Formal verification textual message

For every peer pair, all message-delivery actions are weakly fair.

## Explanation

This quantified conjunction covers the four stages that create, send, receive, and store a message payload. Each action has its own weak-fairness constraint over payloadExchangeState. The assumption excludes schedules that leave a continuously enabled delivery stage unexecuted forever, but does not impose an execution deadline.
