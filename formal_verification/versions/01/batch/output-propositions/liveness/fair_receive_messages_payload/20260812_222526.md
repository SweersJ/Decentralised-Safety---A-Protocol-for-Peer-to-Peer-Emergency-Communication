## Formal verification textual message

Receiving some sent message payload is weakly fair.

## Explanation

This temporal assumption requires the nondeterministic receive action to occur eventually when it remains continuously enabled. Its fairness state set is payloadExchangeState exactly as written in Quint. It does not impose a deadline and does not guarantee execution when enablement is merely intermittent. A behavior violating it is excluded from proofs that use this assumption.
