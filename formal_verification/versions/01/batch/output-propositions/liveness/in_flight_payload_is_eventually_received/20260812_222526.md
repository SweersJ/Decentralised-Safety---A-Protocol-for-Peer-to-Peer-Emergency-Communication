## Quint proposition snapshot

```quint
    temporal in_flight_payload_is_eventually_received =
        fair_receive_messages_payload implies (
            NODES.forall(
                sender => NODES.forall(
                    receiver => isPeerPair(sender, receiver) implies
                        hasInFlightPayload(sender, receiver)
                        leadsTo getPayloadExchangeState(sender, receiver).phase == MessagesReceived
                )
            )
        )
```

## Formal verification formula

$$
\operatorname{WF}_{\{PE\}}(\mathit{someReceiveMessagesPayload})\Rightarrow\forall s,r\in N:\;s\ne r\Rightarrow\bigl((\phi_{sr}=\mathit{MessagesSent})\leadsto(\phi_{sr}=\mathit{MessagesReceived})\bigr)
$$

## Formal verification textual message

Under receive fairness, every in-flight payload eventually reaches MessagesReceived.

## Explanation

The response trigger is the MessagesSent phase identified by hasInFlightPayload, and the response is the same pair reaching MessagesReceived. Universal peer quantification is inside the fair temporal guarantee. Weak fairness excludes continuous starvation of the receive action; a counterexample under that assumption is a sent payload that never advances to receipt.
