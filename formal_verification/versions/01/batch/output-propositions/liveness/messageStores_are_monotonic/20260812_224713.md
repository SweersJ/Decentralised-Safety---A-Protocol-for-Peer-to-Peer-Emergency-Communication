## Formal verification formula

\Box\left(\forall n\in\mathit{NODES}:\;\mathit{messageStore}[n]\subseteq\bigcirc\mathit{messageStore}[n]\right)
$$

## Formal verification textual message

Each node's message store never loses a message between consecutive states.

## Explanation

This temporal safety property compares every node's current store with its next-state store. The subset relation permits new messages to be added but forbids existing messages from disappearing, so it expresses monotonic growth. The declaration is disabled because the current Quint-to-TLA+ conversion rejects the way always encloses a next-state action formula; consequently, this document describes the intended property but does not report a runnable verification result.
