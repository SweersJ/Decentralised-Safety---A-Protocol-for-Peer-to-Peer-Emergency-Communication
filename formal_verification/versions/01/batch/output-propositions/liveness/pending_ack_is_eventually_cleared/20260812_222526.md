## Formal verification textual message

Under acknowledgement-receive fairness, every nonempty acknowledgement set is eventually cleared.

## Explanation

The trigger is pending acknowledgement data and the response is complete removal of that data. Weak fairness prevents a continuously enabled receive-acknowledgement action from being ignored forever. A counterexample satisfying fairness would retain acknowledgements indefinitely after they become pending.
