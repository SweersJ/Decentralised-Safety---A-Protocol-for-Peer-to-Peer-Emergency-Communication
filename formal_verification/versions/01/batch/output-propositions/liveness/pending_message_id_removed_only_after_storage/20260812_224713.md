## Formal verification formula

$$
\forall s,r\in N,\forall id\in\mathit{MESSAGE\_IDS}:\;s\ne r\Rightarrow\Box\left(\left(id\in\mathit{pending}_{sr}\land\bigcirc(id\notin\mathit{pending}_{sr})\right)\Rightarrow\bigcirc(id\in\mathit{messageStore}_{r})\right)
$$

## Formal verification textual message

A pending message identifier may disappear only if it is stored by the receiver in the next state.

## Explanation

This quantified temporal safety rule observes a removal transition: an identifier is pending now but absent from the same pending set in the next state. Such a transition is allowed only when the receiver's next-state message store contains that identifier. It prevents premature pending-state cleanup. The declaration is commented out because its nested always and next-state action expression cannot currently be converted to TLA+ by the configured toolchain.
