## Quint proposition snapshot

```quint
    temporal pending_messages_are_eventually_cleared =
        protocol_fairness implies (
            NODES.forall(
                sender => NODES.forall(
                    receiver =>
                        isPeerPair(sender, receiver) implies
                        MESSAGES.keys().forall(
                            id =>
                                id.in(
                                    getSetMessageIds(
                                        getNodeState(sender, receiver).messages
                                    )
                                )
                                leadsTo not(
                                    id.in(
                                        getSetMessageIds(
                                            getNodeState(sender, receiver).messages
                                        )
                                    )
                                )
                        )
                )
            )
        )
```

## Formal verification formula

$$
\mathit{ProtocolFairness}\Rightarrow\forall s,r\in N,\forall id\in\mathit{MESSAGE\_IDS}:\;s\ne r\Rightarrow\bigl(id\in\mathit{pending}_{sr}\leadsto id\notin\mathit{pending}_{sr}\bigr)
$$

## Formal verification textual message

Under full protocol fairness, every pending message identifier eventually leaves sender-side pending state.

## Explanation

This cleanup response begins when an identifier is pending for a receiver and ends when it is absent from that same pending set. ProtocolFairness covers delivery, acknowledgement, and idle actions, enabling completion of the entire exchange cycle. A fair counterexample retains a pending identifier forever.
