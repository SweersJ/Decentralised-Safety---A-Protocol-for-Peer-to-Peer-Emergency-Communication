## Quint proposition snapshot

```quint
    temporal pending_messages_are_eventually_delivered =
        delivery_fairness implies (
            NODES.forall(
                sender => NODES.forall(
                    receiver =>
                        isPeerPair(sender, receiver) implies
                        MESSAGES.keys().forall(
                            id =>
                                id.in(
                                    getSetMessageIds(
                                        getNodeState(sender, receiver).messages
                                    )
                                )
                                leadsTo id.in(
                                    getSetMessageIds(
                                        getMessagesMessageStore(receiver)
                                    )
                                )
                        )
                )
            )
        )
```

## Formal verification formula

$$
\mathit{DeliveryFairness}\Rightarrow\forall s,r\in N,\forall id\in\mathit{MESSAGE\_IDS}:\;s\ne r\Rightarrow\bigl(id\in\mathit{pending}_{sr}\leadsto id\in\mathit{messageStore}_{r}\bigr)
$$

## Formal verification textual message

Under delivery fairness, every pending message identifier eventually enters the receiver's store.

## Explanation

The trigger is membership in the sender's pending set for a receiver, while the response is membership in that receiver's durable message store. DeliveryFairness supplies weak fairness for add, send, receive, and store actions for every peer pair. A fair counterexample demonstrates a pending message that is never delivered.
