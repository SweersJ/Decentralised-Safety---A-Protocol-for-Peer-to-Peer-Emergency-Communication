## Quint proposition snapshot

```quint
    temporal pending_payload_is_eventually_acknowledged =
        (fair_receive_messages_payload and fair_determine_ack) implies (
            NODES.forall(
                sender => NODES.forall(
                    receiver => isPeerPair(sender, receiver) implies
                        and {
                            getPayload(sender,receiver).messages.size() > 0,
                            getPayloadExchangeState(sender,receiver).phase == MessagesSent,
                        }
                        leadsTo getPayload(sender,receiver).acks.size() > 0
                )
            )
        )
```

## Formal verification textual message

Under receive and acknowledgement-determination fairness, every sent nonempty payload eventually gains an acknowledgement.

## Explanation

This response property starts when a peer payload is nonempty and in MessagesSent. Its target is a nonempty acknowledgement set for that payload. The two weak-fairness premises cover receipt and acknowledgement determination. A fair counterexample would preserve the trigger while never producing any acknowledgement.
