## Quint proposition snapshot

```quint
    temporal protocol_fairness =
        delivery_fairness
        and acknowledgement_fairness
        and NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies
                        idle(sender, receiver)
                            .weakFair(Set(payloadExchangeState))
            )
        )
```

## Formal verification formula

$$
\mathit{DeliveryFairness}\land\mathit{AcknowledgementFairness}\land\forall s,r\in N:\;s\ne r\Rightarrow\operatorname{WF}_{\{PE\}}(\mathit{idle}(s,r))
$$

## Formal verification textual message

The complete protocol is weakly fair for delivery, acknowledgement, and idle actions.

## Explanation

This composite temporal assumption joins all delivery and acknowledgement weak-fairness constraints with weak fairness of idle for every peer pair. It characterizes the admissible schedules used by end-to-end cleanup properties. It does not itself state that a particular payload is delivered; rather, it excludes continuous starvation of each covered action.
