## Formal verification textual message

A change in one exchange direction leaves the reverse-direction payload unchanged in the next state.

## Explanation

This frame-style temporal safety property separates the two directional payload entries of a peer pair. Whenever the selected direction's exchange lifecycle or payload changes, the reverse payload must remain equal to its current value in the next state. It detects unintended cross-direction writes. The declaration is disabled because the current Quint-to-TLA+ conversion rejects the always-wrapped next-state action formula.
