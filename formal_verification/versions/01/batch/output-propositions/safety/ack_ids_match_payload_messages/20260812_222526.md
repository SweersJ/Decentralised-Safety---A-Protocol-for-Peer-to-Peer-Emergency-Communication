## Quint proposition snapshot

```quint
    val ack_ids_match_payload_messages =
        NODES.forall(
            sender => NODES.forall(
                receiver => getPayload(sender,receiver).acks.forall(
                    id => id.in(payloadMessageIds(sender, receiver))
                )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N:\;\mathit{acks}(P_{sr})\subseteq\{\mathit{id}(m)\mid m\in\mathit{messages}(P_{sr})\}
$$

## Formal verification textual message

Every acknowledgement identifier refers to a message in the same payload.

## Explanation

The acknowledgement set may only name identifiers derived from the payload's message set. This domain-integrity constraint excludes acknowledgements for unrelated or nonexistent payload contents. A violation exposes an acknowledgement-generation or payload-mutation inconsistency.
