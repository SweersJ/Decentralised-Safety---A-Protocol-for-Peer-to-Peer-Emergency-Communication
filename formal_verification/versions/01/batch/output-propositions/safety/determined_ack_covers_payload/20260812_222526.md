## Quint proposition snapshot

```quint
    val determined_ack_covers_payload =
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies (
                        getPayloadExchangeState(sender, receiver).ackDetermined
                        implies
                        getPayload(sender, receiver).acks
                            == payloadMessageIds(sender, receiver)
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N,\;s\ne r:\;\mathit{ackDetermined}_{sr}\Rightarrow\mathit{acks}(P_{sr})=\{\mathit{id}(m)\mid m\in\mathit{messages}(P_{sr})\}
$$

## Formal verification textual message

A determined acknowledgement covers exactly all messages in its payload.

## Explanation

Once ackDetermined is true, the acknowledgement identifiers must equal the payload message identifiers. This establishes completeness and excludes extra acknowledgements. A violation exposes partial acknowledgement determination or identifiers unrelated to the current payload.
