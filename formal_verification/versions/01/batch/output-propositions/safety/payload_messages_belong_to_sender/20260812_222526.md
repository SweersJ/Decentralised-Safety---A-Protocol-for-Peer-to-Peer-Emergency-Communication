## Quint proposition snapshot

```quint
    val payload_messages_belong_to_sender =
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies
                    getPayload(sender, receiver).messages.forall(
                        m => m.in(getMessagesMessageStore(sender))
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N,\;s\ne r:\;\forall m\in P_{sr}.\mathit{messages}:\;m\in MS_s
$$

## Formal verification textual message

Every payload message belongs to the sender's message store.

## Explanation

The invariant prevents a sender from transmitting messages it does not possess. It quantifies over peer pairs and every payload message, then checks membership in the originating node's store. A counterexample indicates fabrication, misaddressing, or an inconsistent payload update.
