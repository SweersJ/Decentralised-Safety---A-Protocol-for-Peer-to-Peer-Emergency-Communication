## Quint proposition snapshot

```quint
    val pending_acks_imply_nonempty_payload =
        NODES.forall(
            sender => NODES.forall(
                receiver => getPayload(sender,receiver).acks.size() > 0
                    implies getPayload(sender,receiver).messages.size() > 0
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N:\;|\mathit{acks}(P_{sr})|>0\Rightarrow|\mathit{messages}(P_{sr})|>0
$$

## Formal verification textual message

A nonempty acknowledgement set implies a nonempty message payload.

## Explanation

Acknowledgements are meaningful only in relation to payload messages. This invariant prevents residual or fabricated acknowledgements from existing with an empty payload. A counterexample indicates cleanup occurred in an invalid order or acknowledgement state was produced without message context.
