## Quint proposition snapshot

```quint
    val pending_messages_belong_to_sender =
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies
                    getNodeState(sender, receiver).messages.forall(
                        m => m.in(getMessagesMessageStore(sender))
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N,\;s\ne r:\;\forall m\in NS_{sr}.\mathit{messages}:\;m\in MS_s
$$

## Formal verification textual message

Every message pending for a receiver belongs to the sender.

## Explanation

The per-receiver node state represents messages the sender intends to synchronize. This invariant makes that pending set a subset of the sender's durable message store for every peer pair. A violation means scheduling state references a message unavailable at its supposed source.
