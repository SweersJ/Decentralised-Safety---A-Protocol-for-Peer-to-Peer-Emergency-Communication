## Quint proposition snapshot

```quint
    val reverse_payloadState_is_always_empty = 
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies
                    (
                        // Allow both directions to be empty only when both directions are idle.
                        (
                            (
                                getPayloadExchangeState(sender, receiver).phase == Idle or
                                getPayloadExchangeState(sender, receiver).phase == AckReceived
                            ) 
                            and
                            (
                                getPayloadExchangeState(receiver, sender).phase == Idle or
                                getPayloadExchangeState(receiver, sender).phase == AckReceived
                            )
                        )
                        or
                        // During sync activity, at least one direction must differ from EMPTY_PAYLOAD.
                        (
                            not(isDefaultPayloadState(sender, receiver)) or
                            not(isDefaultPayloadState(receiver, sender))
                        )
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r \in \mathit{NODES}:\; s\ne r \Rightarrow \bigl(((\phi_{sr}\in\{\mathit{Idle},\mathit{AckReceived}\})\land(\phi_{rs}\in\{\mathit{Idle},\mathit{AckReceived}\}))\lor(P_{sr}\ne\mathit{EMPTY\_PAYLOAD}\lor P_{rs}\ne\mathit{EMPTY\_PAYLOAD})\bigr)
$$

## Formal verification textual message

For each peer pair, either both directions are idle-like or at least one directional payload is non-default.

## Explanation

This universally quantified consistency rule relates both directions of a peer exchange. It allows both payloads to be empty only while both exchange phases are Idle or AckReceived; during other activity it requires at least one direction to carry non-default payload state. It tests payload and lifecycle state together. A violation would reveal active exchange metadata with no corresponding payload in either direction.
