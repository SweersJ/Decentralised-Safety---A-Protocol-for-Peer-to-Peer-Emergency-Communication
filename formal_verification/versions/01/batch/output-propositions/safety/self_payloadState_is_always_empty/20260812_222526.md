        )

## Formal verification formula

$$
\forall n \in \mathit{NODES}:\; \mathit{payloadState}[n][n] = \mathit{EMPTY\_PAYLOAD}
$$

## Formal verification textual message

Every payload addressed by a node to itself remains empty.

## Explanation

This diagonal-state invariant prevents the model from treating a node as its own transport peer. Equality with the default payload means identifier zero and empty acknowledgement and message sets. A counterexample identifies an action that writes protocol traffic into a self-addressed payload entry.
