## Quint proposition snapshot

```quint
    val sent_ack_ids_match_stored_messages  =
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies (
                        getPayloadExchangeState(sender, receiver).phase == AckSent 
                        implies
                        getPayload(sender, receiver).acks.forall(
                            id => id.in(
                                getSetMessageIds(messageStore.get(receiver))
                            )
                        )
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N,\;s\ne r:\;\phi_{sr}=\mathit{AckSent}\Rightarrow\mathit{acks}(P_{sr})\subseteq\{\mathit{id}(m)\mid m\in MS_r\}
$$

## Formal verification textual message

Whenever an acknowledgement has been sent, every acknowledged message is stored by the receiver.

## Explanation

This phase-conditional soundness rule connects transport lifecycle, acknowledgement contents, and the receiver's durable store. It rules out acknowledging data before storage. A counterexample would show AckSent with an identifier absent from the receiver's stored messages.
