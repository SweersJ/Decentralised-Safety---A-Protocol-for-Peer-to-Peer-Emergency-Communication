## Explanation

This cardinality constraint fixes the modeled participant set to two elements, Alice and Bob. It is a state predicate over the constant node domain rather than mutable protocol state. When checked as an invariant, success confirms that every explored state uses the intended two-node abstraction; a violation would indicate that the configured model domain no longer matches the assumptions used by the peer-pair propositions.
