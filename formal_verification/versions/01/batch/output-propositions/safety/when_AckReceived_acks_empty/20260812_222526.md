## Quint proposition snapshot

```quint
    val when_AckReceived_acks_empty = 
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies (
                        getPayloadExchangeState(sender, receiver).phase == AckReceived
                        implies
                        getPayload(sender, receiver).acks.size() == 0
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N,\;s\ne r:\;\phi_{sr}=\mathit{AckReceived}\Rightarrow|\mathit{acks}(P_{sr})|=0
$$

## Formal verification textual message

After acknowledgement receipt, the acknowledgement set is empty.

## Explanation

AckReceived represents completion of acknowledgement processing at the original sender. The associated acknowledgement set must already have been cleared. A counterexample indicates stale acknowledgement data survived the receive transition.
