## Quint proposition snapshot

```quint
    val when_AckSent_messagesStored_ackDetermined_acks_non_empty =
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies (
                        getPayloadExchangeState(sender, receiver).phase == AckSent
                        implies
                        and {
                            getPayloadExchangeState(sender, receiver).messagesStored,
                            getPayloadExchangeState(sender, receiver).ackDetermined,
                            getPayload(sender, receiver).acks.size() > 0
                        }
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N,\;s\ne r:\;\phi_{sr}=\mathit{AckSent}\Rightarrow(\mathit{messagesStored}_{sr}\land\mathit{ackDetermined}_{sr}\land|\mathit{acks}(P_{sr})|>0)
$$

## Formal verification textual message

AckSent implies completed storage, acknowledgement determination, and nonempty acknowledgements.

## Explanation

This phase-consistency invariant encodes the prerequisites for sending an acknowledgement. Both processing flags must be true and the payload must carry an acknowledgement identifier. A violation reveals that the protocol advanced before completing required receiver-side work.
