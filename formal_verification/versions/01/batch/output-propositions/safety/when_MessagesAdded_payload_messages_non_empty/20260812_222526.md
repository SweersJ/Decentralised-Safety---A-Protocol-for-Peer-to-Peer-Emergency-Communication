## Quint proposition snapshot

```quint
    val when_MessagesAdded_payload_messages_non_empty =
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies (
                        getPayloadExchangeState(sender, receiver).phase == MessagesAdded
                        implies
                        getPayload(sender, receiver).messages.size() > 0
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N,\;s\ne r:\;\phi_{sr}=\mathit{MessagesAdded}\Rightarrow|\mathit{messages}(P_{sr})|>0
$$

## Formal verification textual message

The MessagesAdded phase always contains at least one payload message.

## Explanation

The lifecycle may claim messages have been added only when the corresponding payload is nonempty. This guards agreement between the phase tag and payload contents. A violation indicates a phase transition occurred without populating the payload.
