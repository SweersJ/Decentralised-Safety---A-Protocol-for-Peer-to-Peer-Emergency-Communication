## Quint proposition snapshot

```quint
    val when_MessagesSent_payload_messages_non_empty =
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies (
                        getPayloadExchangeState(sender, receiver).phase == MessagesSent
                        implies
                        getPayload(sender, receiver).messages.size() > 0
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N,\;s\ne r:\;\phi_{sr}=\mathit{MessagesSent}\Rightarrow|\mathit{messages}(P_{sr})|>0
$$

## Formal verification textual message

The MessagesSent phase always contains at least one payload message.

## Explanation

A sent-message lifecycle state must be backed by concrete payload messages. The predicate connects the phase marker to payload cardinality for every peer pair. A counterexample represents an empty transmission or premature payload cleanup.
