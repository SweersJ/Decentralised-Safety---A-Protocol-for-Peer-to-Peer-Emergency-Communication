## Quint proposition snapshot

```quint
    val when_ackDetermined = 
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies (
                        getPayloadExchangeState(sender, receiver).ackDetermined
                        implies
                        getPayloadExchangeState(sender, receiver).phase.in(Set(MessagesReceived, AckSent, AckReceived))
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N,\;s\ne r:\;\mathit{ackDetermined}_{sr}\Rightarrow\phi_{sr}\in\{\mathit{MessagesReceived},\mathit{AckSent},\mathit{AckReceived}\}
$$

## Formal verification textual message

The acknowledgement-determined flag is true only in compatible phases.

## Explanation

Acknowledgement determination begins after message receipt and may remain true through acknowledgement sending and receipt. This invariant excludes the flag from earlier phases. A violation indicates lifecycle flags and phase progression disagree.
