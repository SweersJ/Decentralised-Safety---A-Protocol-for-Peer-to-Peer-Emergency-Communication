## Quint proposition snapshot

```quint
    val when_idle_not_messageStored_and_not_ackDetermined =
        NODES.forall(
            sender => NODES.forall(
                receiver => 
                    isPeerPair(sender, receiver) implies (
                        getPayloadExchangeState(sender, receiver).phase == Idle
                        implies
                        and {
                            not(getPayloadExchangeState(sender, receiver).messagesStored),
                            not(getPayloadExchangeState(sender, receiver).ackDetermined)
                        }
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N,\;s\ne r:\;\phi_{sr}=\mathit{Idle}\Rightarrow(\neg\mathit{messagesStored}_{sr}\land\neg\mathit{ackDetermined}_{sr})
$$

## Formal verification textual message

An idle exchange has neither processing flag set.

## Explanation

The Idle phase represents a clean lifecycle boundary. Both messagesStored and ackDetermined must be false for every peer pair. A counterexample reveals incomplete lifecycle cleanup or an action that entered Idle while retaining processing history.
