## Quint proposition snapshot

```quint
    val when_messagesStored = 
        NODES.forall(
            sender => NODES.forall(
                receiver =>
                    isPeerPair(sender, receiver) implies (
                        getPayloadExchangeState(sender, receiver).messagesStored
                        implies
                        getPayloadExchangeState(sender, receiver).phase.in(Set(MessagesReceived, AckSent, AckReceived))
                    )
            )
        )
```

## Formal verification formula

$$
\forall s,r\in N,\;s\ne r:\;\mathit{messagesStored}_{sr}\Rightarrow\phi_{sr}\in\{\mathit{MessagesReceived},\mathit{AckSent},\mathit{AckReceived}\}
$$

## Formal verification textual message

The messages-stored flag is true only in compatible phases.

## Explanation

Storage can occur once messages are received and may remain recorded through acknowledgement phases. The predicate restricts the flag to those lifecycle phases. A counterexample reveals premature storage marking or failure to reset the flag.
