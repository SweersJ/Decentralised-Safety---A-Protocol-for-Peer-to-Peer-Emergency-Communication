## Quint proposition snapshot

```quint
    val can_have_delivered_payload =
        NODES.exists(
            sender => NODES.exists(
                receiver => 
                    and {
                        isPeerPair(sender, receiver),
                        getPayloadExchangeState(sender, receiver).phase == MessagesReceived,
                    }
            )
        )
```

## Formal verification formula

$$
\exists s,r\in N:\;s\ne r\land\mathit{payloadExchangeState}[s][r].\mathit{phase}=\mathit{MessagesReceived}
$$

## Formal verification textual message

A reachable state can contain a delivered payload.

## Explanation

The witness seeks a peer exchange whose lifecycle has reached MessagesReceived. Success establishes that message-payload receipt is feasible in at least one execution and supplies a concrete reachability trace. It is not a universal delivery guarantee and carries no fairness assumption.
