## Formal verification textual message

A reachable state can contain an in-flight message payload.

## Explanation

Through hasInFlightPayload, this witness requires a peer exchange in the MessagesSent phase. A successful trace demonstrates that the send action and lifecycle progression can produce an in-flight payload. It does not assert delivery or universal progress; those obligations belong to temporal propositions.
