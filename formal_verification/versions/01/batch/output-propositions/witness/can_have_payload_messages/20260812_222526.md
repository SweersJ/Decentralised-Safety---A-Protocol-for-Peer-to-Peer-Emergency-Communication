## Quint proposition snapshot

```quint
    val can_have_payload_messages =
        NODES.exists(
            sender => NODES.exists(
                receiver => 
                    and {
                        isPeerPair(sender, receiver),
                        getPayload(sender,receiver).messages.size() > 0,
                    }
            )
        )
```

## Formal verification formula

$$
\exists s,r\in N:\;s\ne r\land|\mathit{payloadState}[s][r].\mathit{messages}|>0
$$

## Formal verification textual message

A reachable state can contain messages in a payload.

## Explanation

The witness searches for a reachable peer payload with at least one message. Success confirms that payload construction can occur and provides a concrete trace into that state. Because the formula is existential, it establishes feasibility only, not that every run eventually creates such a payload.
